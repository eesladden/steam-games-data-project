# Steam Games Data Analysis

**Dataset source (URL):** https://www.kaggle.com/datasets/fronkongames/steam-games-dataset

## Project objective
The main goal of this project is to discover whether game success (>80% positive reviews and midpoint of estimated owners greater than the median) can be predicted by specific attribute, focusing on games from the platform Steam. I would also like to examine the data collected post-release to see what the relationships are between pre-release and post-release data.

## Instructions for running the code
1. Clone the git repository into your file directory
2. Open the `\src` folder in the cloned folder in a Command Prompt or Terminal
3. Depending on your device, run:
- `python -m streamlit run app.py`
OR
- `streamlit run app.py`
4. The Streamlit appication should open in your browser, where you can see a version of the report
- The AI responses will be different than my final ones due to differing sessions
5. To see the accurate final report, simply open the pdf file in the `\report` folder
